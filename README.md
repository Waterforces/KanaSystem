# 🛒 Kana POS - ระบบขายหน้าร้านสำหรับ iPhone

ระบบ Point of Sale (POS) ที่ออกแบบมาเพื่อการใช้งานบน **iPhone โดยเฉพาะ** รองรับการสแกนบาร์โค้ด/คิวอาร์โค้ดด้วยกล้องหลัง คำนวณรายรับ-รายจ่าย สรุปกำไรสุทธิ และส่งออกเป็นไฟล์ **Excel (.xlsx)** ได้ในตัว พร้อมระบบจัดการสินค้าและพิมพ์ป้ายบาร์โค้ด

---

## ✨ ฟีเจอร์เด่น (Key Features)

1. **ออกแบบสำหรับ iPhone (Mobile First UX)**
   - ปุ่มกดขนาดใหญ่ สัมผัสง่ายด้วยนิ้วโป้งเดียว
   - รองรับขอบจอ iPhone ทุกรุ่น (Dynamic Island และแถบ Home ด้านล่าง)
   - ป้องกันหน้าจอซูมเข้าเองขณะแตะกรอกข้อมูลตัวเลข
   - สามารถกด "เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen) เพื่อใช้งานเต็มจอเหมือนแอปจริง

2. **ระบบคิดเงินหน้าร้าน (POS)**
   - สแกนขายสินค้าผ่านกล้องหลัง iPhone หรือแตะเลือกจากรายการ
   - มีปุ่มลัดรับเงินด่วน (พอดี, 20, 50, 100, 500, 1,000) พร้อมคำนวณเงินทอนอัตโนมัติ
   - ตัดสต็อกสินค้าทันทีเมื่อบันทึกการขาย
   - มีเสียงแจ้งเตือน (Beep) และเอฟเฟกต์สั่น/พลุเมื่อบันทึกการขายสำเร็จ

3. **คลังสินค้า & บาร์โค้ด (Admin Product Management)**
   - เพิ่ม แก้ไข และลบสินค้าได้ด้วยตนเอง
   - ระบบสุ่มรหัสบาร์โค้ดอัตโนมัติ หรือใช้กล้องสแกนบาร์โค้ดเดิมจากซองสินค้า
   - แสดงป้ายสินค้าทั้ง **บาร์โค้ดแท่ง (Barcode)** และ **คิวอาร์โค้ด (QR Code)**
   - รองรับการสั่งพิมพ์ป้ายสติ๊กเกอร์ติดสินค้าได้ทันที

4. **บัญชีรายรับ-รายจ่าย & ส่งออกไฟล์ Excel**
   - สรุปตัวเลขทางการเงินแบบเรียลไทม์: **รายรับรวม**, **รายจ่ายร้าน**, และ **กำไรสุทธิ**
   - กรองดูข้อมูลย้อนหลังได้ทั้ง **วันนี้**, **เดือนนี้**, หรือ **ทั้งหมด**
   - จดบันทึกค่าใช้จ่ายร้านค้าเพิ่มเติมได้ (เช่น ค่าน้ำแข็ง, ค่าถุง, ค่าเช่าที่)
   - **ปุ่มส่งออก Excel (.xlsx)** รวม 5 แผ่นงาน (สรุปภาพรวม, ประวัติบิลขาย, รายละเอียดสินค้าที่ขาย, รายจ่ายร้าน, สต็อกคงเหลือ)

5. **ทำงานแบบออฟไลน์ 100% & ปลอดภัย**
   - เก็บข้อมูลลงในหน่วยความจำของเครื่อง iPhone (IndexedDB)
   - ทำงานได้รวดเร็ว ไม่ต้องต่ออินเทอร์เน็ตระหว่างวัน ไม่มีค่าบริการรายเดือน
   - มีปุ่มสำรองข้อมูล (Backup) และกู้คืนข้อมูล (Restore) เป็นไฟล์ JSON

## 🛠️ วิธีการรันบนเครื่องคอมพิวเตอร์ (Local Development)

```bash
# 1. ติดตั้งไลบรารี
npm install

# 2. เริ่มต้นเซิร์ฟเวอร์ทดสอบ
npm run dev
```

เปิดเบราว์เซอร์ไปที่ลิงก์ที่แสดงใน Terminal (เช่น `http://localhost:5173`)

## 🎨 การปรับแต่งโค้ดด้วยตนเอง (Easy Customization)

โครงสร้างโค้ดถูกออกแบบให้แก้ไขได้ง่าย แม้ไม่มีประสบการณ์เขียนโค้ดมาก่อน:

### 1. แก้ไขชื่อร้าน สกุลเงิน หรือหมวดหมู่
เปิดไฟล์ `src/config/shopConfig.ts`:
```typescript
export const SHOP_CONFIG = {
  shopName: 'ชื่อร้านของคุณ',
  currency: '฿',
  productCategories: ['ทั้งหมด', 'เครื่องดื่ม', 'เบเกอรี่', 'อาหาร'],
  expenseCategories: ['ซื้อวัตถุดิบ', 'ค่าเช่าที่', 'อื่นๆ'],
  quickCashAmounts: [20, 50, 100, 500, 1000],
}
```

### 2. ปรับแต่งหน้าจอต่างๆ
- **หน้าขายสินค้าหน้าร้าน:** `src/pages/PosPage.tsx`
- **หน้าจัดการคลังสินค้า:** `src/pages/ProductsPage.tsx`
- **หน้าบัญชีและกำไร:** `src/pages/FinancePage.tsx`
- **ฟังก์ชันสร้างไฟล์ Excel:** `src/utils/excelHelper.ts`

## 🚀 วิธีนำขึ้น GitHub Pages (ฟรี 100% + มี HTTPS)

1. สร้าง Repository ใหม่บน GitHub แล้วนำโค้ดในโฟลเดอร์นี้ขึ้นไป (Push to GitHub)
2. ไปที่หน้า GitHub Repository ของคุณ -> เลือกแท็บ **Settings**
3. ที่เมนูด้านซ้าย เลือกหัวข้อ **Pages**
4. ในส่วน **Build and deployment**:
   - ช่อง **Source** ให้เลือกเป็น **GitHub Actions**
5. รอประมาณ 1-2 นาที ระบบจะ Build และ Deploy อัตโนมัติ คุณจะได้ลิงก์เว็บไซต์ HTTPS สำหรับเปิดบน iPhone ทันที!

## 📱 วิธีเปิดใช้งานเต็มจอเหมือนแอปบน iPhone

1. เปิด Safari บน iPhone แล้วเข้าไปที่ลิงก์ GitHub Pages ของคุณ
2. แตะปุ่ม **แชร์ (สี่เหลี่ยมลูกศรชี้ขึ้น 📤)** ที่แถบด้านล่างของ Safari
3. เลือก **"เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen)**
4. แตะเปิดจากไอคอนบนหน้าจอโฮม จะได้แอป POS หน้าจอเต็ม ไม่มีแถบ URL กวนใจ!
