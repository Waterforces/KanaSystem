# 🛒 Kana POS - ระบบขายหน้าร้านสำหรับ iPhone และ iPad (Next.js)

ระบบ Point of Sale (POS) สร้างด้วย **Next.js (Static Export)** ออกแบบสำหรับใช้งานบน **iPhone และ iPad** รองรับการสแกนบาร์โค้ดด้วยกล้อง, โหมดกลางคืน (Dark Mode), ซิงก์ข้อมูล 2 ทิศทางกับ Google Sheets, แยกยอดขายตามทำเลร้านค้าอัตโนมัติ และวิเคราะห์สินค้าขายดี

---

## ✨ ฟีเจอร์หลัก (Key Features)

1. **รองรับทั้ง iPhone และ iPad + โหมดกลางคืน (Dark Mode)**
   - ปรับขนาดคอลัมน์ พื้นที่กด และ **ขยายฟอนต์ให้ใหญ่ขึ้นบนหน้าจอ iPad**
   - รองรับโหมดสว่าง / โหมดกลางคืน / ตามเครื่อง (สลับได้จากหน้าตั้งค่า)
   - รองรับ Safe Area (Dynamic Island และแถบ Home ด้านล่าง) พร้อมเพิ่มลงหน้าจอโฮมได้

2. **ระบบคิดเงินหน้าร้าน (POS)**
   - สแกนบาร์โค้ดผ่านกล้องหลังหรือแตะเลือกจากรายการ
   - รองรับส่วนลดรายชิ้น, เงินสด (ปุ่มรับเงินด่วน + คำนวณเงินทอน), PromptPay และโครงการไทยช่วยไทย (40%)
   - ตรวจสต็อกคงเหลือสดก่อนตัดบิล พร้อมเสียงแจ้งเตือนและเอฟเฟกต์พลุ

3. **คลังสินค้า & บาร์โค้ด (`src/app/products/page.tsx`)**
   - เพิ่ม แก้ไข ลบสินค้า จัดการหมวดหมู่ อัปโหลดรูปภาพ และพิมพ์ป้ายบาร์โค้ด CODE128

4. **หน้า Data & วิเคราะห์ (`src/app/data/page.tsx`)**
   - แสดงผล 2 แท็บหลักคือ **เดือนนี้** (รายวันเรียงจากบนลงล่าง) และ **ปีนี้** (รายเดือนเรียงจากบนลงล่าง) พร้อมปุ่มด้านข้างสำหรับกดดูรายการซื้อขายและรายจ่ายด้านใน (ยกเลิกบิลคืนสต็อก / ลบรายจ่ายได้)
   - **แยกยอดตามทำเลร้านค้า:** วันหรือเดือนที่มีการขายมากกว่า 1 ทำเลจะแสดงการ์ดแยกกันเรียงตามชื่อสถานที่ตั้ง ส่วนรายการที่ไม่ได้กรอกทำเลจะนับยอดรวมกัน
   - **ปุ่มวิเคราะห์:** วิเคราะห์อันดับประเภทสินค้าที่ขายดีที่สุด, Top สินค้าขายดีรายชิ้น และสัดส่วนช่องทางชำระเงิน แยกดูตามช่วงเวลาและทำเลได้
   - รองรับการจดรายจ่าย, ซิงก์ชีต, และ Clear ข้อมูลแบบ Cascading

5. **หน้าตั้งค่า (`src/app/settings/page.tsx`)**
   - **ที่อยู่ / ทำเลร้านค้า (ด้านบนสุด):** เลือกกรอกหรือไม่กรอกก็ได้ เก็บเฉพาะในเครื่องนั้น (ไม่ซิงก์ข้ามเครื่อง), เชื่อมเข้ากับหน้า Data และ Google Sheets, และ **ล้างชื่ออัตโนมัติทุกเที่ยงคืน (00:00 น.)**
   - สวิตช์เปิด/ปิด ช่องทางชำระเงิน **ไทยช่วยไทย**
   - ปุ่มเปลี่ยนโหมด **ตามเครื่อง / โหมดสว่าง / โหมดกลางคืน**

---

## 🛠️ วิธีการรันและ Build

```bash
# 1. ติดตั้งไลบรารี
npm install

# 2. รันเซิร์ฟเวอร์ทดสอบ
npm run dev

# 3. ตรวจสอบ TypeScript และ Unit Tests
npm run typecheck
npm run test:unit

# 4. สร้างไฟล์ Static Export (โฟลเดอร์ out/)
npm run build
```

## 📊 การอัปเดต Google Apps Script (`google-apps-script.js`)

เมื่ออัปเดตเวอร์ชันใหม่นี้ ให้นำโค้ดใน [`google-apps-script.js`](google-apps-script.js) ไปวางทับและกด **Deploy > Manage deployments > New version** ใน Google Apps Script เพื่อให้ชีตรองรับคอลัมน์ **ทำเลร้านค้า** (คอลัมน์ที่ 10) ได้ครบถ้วน
